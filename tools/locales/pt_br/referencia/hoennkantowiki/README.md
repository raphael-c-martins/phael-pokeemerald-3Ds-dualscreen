# Referência: HoennKantoWiki (Geração 3)

Cópia de `data/gen3/` do HoennKantoWiki (github.com/carlosmozart, commit
`fd1fe688`, 08/10/2026), para consultar a tradução que o wiki já tem sem
mexer no original. **Só consulta**: nada daqui entra no jogo diretamente, e
as mudanças vão para o wiki, não para esta cópia.

O que interessa à tradução do Emerald:

- `gen3/i18n/pt.json`: `pokedex` (386 descrições da POKéDEX), `moves` (354
  descrições de golpes), `abilities` (76 habilidades, nome e descrição),
  `genera` (279 categorias, “Pokémon Semente”).
- `gen3/item-descriptions.json`: descrições de itens segurados (en/pt).
- `gen3/key-items.json`: onde achar os itens-chave, em português.

O wiki usa alguns termos que não são os oficiais do Brasil (HP em vez de PS,
Grama em vez de Planta): ao reaproveitar, siga o
[GLOSSARIO.md](../../GLOSSARIO.md) e refaça as quebras de linha para as
janelas do jogo.
